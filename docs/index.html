Jarvis

A small AI assistant that runs on your own computer.

Jarvis is a chat assistant that runs entirely on hardware you own. There is no account, no API key, and no subscription. Once it is installed, it keeps working with the internet unplugged.

It remembers things you tell it between sessions, and it can search the web when a question needs current information. It runs on a desktop, or on a Raspberry Pi quietly enough to leave in a cupboard.

It is about 1,400 lines of Python and uses nothing outside the standard library. There is no pip install step.

Install it

You need two things first. Both are free, and both are downloaded from their own official sites, not from here:

Download Ollama →
ollama.com/download — runs the model on your machine. Required on every platform.
Download Python →
python.org/downloads — version 3.10 or newer. Already installed on Raspberry Pi OS and macOS, so check with python3 --version before you download it.

On Windows, tick Add python.exe to PATH in the Python installer. If you miss it, every command below fails with "python is not recognized" and there is no obvious clue why.

1. Install Ollama

Use the download page above, or install it from a terminal.

On Windows:

winget install Ollama.Ollama

On a Raspberry Pi, Linux or macOS:

curl -fsSL https://ollama.com/install.sh | sh

2. Download a model

Pick your hardware and this will tell you which one to get. Jarvis makes the same choice by itself at startup; this is only so you know what you are in for.

3. Get Jarvis and run it

git clone https://github.com/drrahul1978-lgtm/jarvis.git
cd jarvis
python jarvis.py

On a Raspberry Pi there is an installer that does the whole job — checks the board, increases swap if it is too small, installs Ollama, downloads the right model, and sets Jarvis to start when the Pi powers on: 

./deploy/install_pi.sh

Talking to it out loud

python jarvis.py --voice

Jarvis reads its answers aloud, starting as soon as the first sentence is finished rather than waiting for the whole reply. Nothing needs installing for this — Windows, macOS and most Linux desktops already have a speech engine, and on a Raspberry Pi it is one package away (sudo apt install espeak-ng).

Talking to it does need extra packages, because capturing a microphone and transcribing speech cannot be done with Python alone: 

pip install -r requirements-voice.txt

Without them --voice still works — it speaks the answers and you type the questions, and it tells you so at startup rather than failing. Press Enter on an empty line to talk; recording stops by itself when you do.

Hands-free

With a microphone attached, Jarvis offers hands-free listening at startup, or you can ask for it directly: 

python jarvis.py --wake

It then waits quietly until it hears its name, chirps to show it is paying attention, and listens for your question. Say the question in the same breath — "Jarvis, what time is it" — and it answers straight away instead of making you repeat yourself. /wake off turns it back off mid-session, and Ctrl-C leaves it, since while hands-free is on the microphone has the floor.

Matching is forgiving on purpose, because speech recognition mangles a one-word name constantly. It is not forgiving enough to trigger on ordinary speech: a false wake is more irritating than a missed one.

A better voice

The voices built into Windows and Raspberry Pi OS are flat, and on Windows they are American. One command fetches a considerably better British one: 

python deploy/get_voice.py

You can hear every available voice before choosing at rhasspy.github.io/piper-samples, then pass any name to --voice. Inside Jarvis, /voice switches between the ones you have downloaded and adjusts speed and volume without restarting.

These are synthetic voices in a British register. None of them imitates any particular performer, and cloning a real person's voice is not something this project does.

What it can and cannot do

Tested on a desktop with the internet disconnected.
Conversation and reasoningWorks offline
Remembering across sessionsWorks offline
Checking system statusWorks offline
Searching the webNeeds a connection, and says so when it hasn't got one

Be realistic about the model. A model small enough to run on a Raspberry Pi is not as capable as the large hosted assistants, and it will occasionally state something wrong with total confidence. During testing it claimed the Raspberry Pi 5 launched in 2022, which is not right. It is genuinely useful for conversation, drafting, explaining and quick lookups. It is not a research assistant.

Smaller models also follow instructions more loosely. Below roughly 3 billion parameters, asking plainly — "search the web for X" — works where hinting does not.

Speed

A Raspberry Pi has no GPU, so all of this runs on the processor.
HardwareSpeedFirst reply
Desktop with a modern GPU40+ words/sec2–5 sec
Raspberry Pi 5, 8GB3–5 words/sec30–60 sec
Raspberry Pi 4, 4GB1–2 words/sec60–90 sec

The first reply is slow because the model is being read off the disk. Later replies in the same sitting are much faster. If you are using a Raspberry Pi, use an SSD or a fast A2 memory card — a cheap card is the single biggest thing that makes this feel broken.

Questions people ask

Is this its own AI, or just a wrapper?

The reasoning comes from an open-weights model — Qwen or Llama — run by Ollama. That part is not mine and I would not claim it. What is built here is everything around it: the memory that survives restarts, the tools it uses to search and read pages, the hardware detection, and the Raspberry Pi service. Without that code the same model has no memory and no way to look anything up.

Does anything get sent anywhere?

Your conversations stay on your machine. The only outbound traffic is a web search, and only when it decides it needs one — you can see each search in the transcript as it happens.

Can I change its personality?

Yes. It is a block of text in one file, core/persona.py. Edit it, and you have a different assistant with a different name and manner.

Can I try yours instead of installing it?

No, and that is deliberate. Running it means running it on your own machine, which is the entire point. Opening mine to the internet would undo the thing that makes it worth having.
